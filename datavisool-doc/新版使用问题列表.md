# 新版使用问题列表

本清单记录新版使用中已确认的问题、限制和处理规则。具体项目的外部资源与数据缺失，应先区分来源，不直接认定为新版程序缺陷。

## 旧 Desktop CLI 组件的导入规则

- 用户确认：对于 CLI 版本未知的旧组件，仍按当前静态转换规则处理；可识别的入口、资源加载格式及已核对接口正常转换，无法可靠转换的情况明确拒绝导入并提示原因。
- 当前已核对本地旧 SDK 0.2.0 的成员；其他版本不因版本号未知而直接拒绝，也不据此宣称其行为已完整验证。`FetchUtil`、未知成员和无法安全判断的动态访问仍按既定规则拒绝。
- 后续若实际项目遇到转换失败或转换后行为不一致，在本清单记录组件、文件、具体写法、报错及处理状态，不记录用户密钥或个人数据。

## 项目包自身缺少的资源

用户提供的 `LCP多项目非加密.zip` 引用了 `6b106d3ae4fd4ca89ff3d331acb2b37a.jpg`，该图片不在原始 ZIP 内，且包内 `err.log` 已记录该文件缺失。这是源包缺少资源，不作为新版导入程序造成资源丢失的证据；导入时仍应提示无法关联的资源。

## 旧 UI 与新版 UI 的滚动条颜色差异

- 已确认旧 UI 的 TextArea、Select 和 SearchableSelect 滚动条默认颜色为 `rgba(99, 122, 177, .52)`；新版通过 `--datavisool-scrollbar-thumb` 提供主题覆盖，未设置时使用 `rgba(113, 130, 190, .28)`。
- 用户决定：保留新版颜色并记录差异。旧组件转换后使用新版默认样式，不为此恢复旧颜色。
