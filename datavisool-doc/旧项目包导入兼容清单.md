# 旧项目包导入兼容清单

核对日期：2026-11-04。范围是当前 Web 仓库中项目包导入调用链：`ImportController.importProject` → `ProjectServiceImpl.importProject` → `ProjectArchiveCompatHelper.importProject`，以及调用的旧组件、项目数据和资源处理。前端负责上传与提示；以下转换由服务端导入执行。清单是本次源码盘点，不代表所有历史版本或真实项目均已验证。

## 旧包与结构识别

| 项目 | 实现与处理 | 移除或复核条件 |
| --- | --- | --- |
| 无清单 `.lc` ZIP | `ProjectArchiveCompatHelper.importLegacyProject` 扫描一个 `.lc` 文件及图片、字体、组件、动态脚本目录；`isLegacyAssetEntry` 按路径识别，`verifyLegacyEntryCrc` 校验读取内容；同包多个 `.lc` 报错。项目 JSON、组件和资源继续经过下面的转换与映射。 | 停止支持无清单旧包后，连同旧入口、CRC 和目录识别一起移除；新版清单包验证仍需保留。 |
| 旧清单格式标识 | `LEGACY_EXPORT_FORMAT` / `isSupportedProjectFormat` 接受 `light-chaser-project`；新导出使用 `datavisool-project`。 | 停止支持带旧标识的项目包后，仅移除旧标识的判断。 |
| 清单版本与模式 | `resolveManifestImportMode` 接受版本 1，也接受未提供版本；根据 `projects` 判断单项目或多项目，根据加密标记识别整包加密。无加密外壳的版本大于 3 被拒绝；加密外壳解密后再次检查内部清单。版本 1 真实来源和样本尚未确认。 | 停止接受版本 1 或缺失版本的包时单独收紧；保留当前版本 2、3 和加密外壳。 |
| 省略字段的清单 | 单项目缺少 `project.dataPath` 时默认 `project/project.json`；`verifyManifestFiles` 在 `files` 缺失或为空时不做文件清单校验；已列出的文件仍按提供的信息校验。这里是可观测的宽松输入，并未确认它们只来自旧包。 | 确认当前 Web / Desktop 包都提供这些字段、且不再支持省略字段的包后，分别收紧对应回退，不移除已有文件校验。 |
| 脚本归属回退 | `importDynamicScripts` 对项目脚本在没有可用项目映射或 `ownerSourceProjectId` 时归入目标项目；空 `scope` 按全局处理。非空未知 scope 和明确引用不存在项目的情况会拒绝。单项目与多项目流程共用该逻辑。 | 先确认仍支持的包如何表达脚本归属，再单独调整缺失字段回退；保留新版项目映射。 |

## 旧项目内容转换

| 项目 | 实现与处理 | 移除或复核条件 |
| --- | --- | --- |
| 旧压缩数据 | `decodeImportedProjectData` 在导入时解码 `LCPZ1:gzip:` 和二进制式 `LCPZ` 版本 1 / gzip 前缀；同时处理当前 `DVZ1:gzip:`，未知格式与损坏数据报错，解压受大小限制。 | 停止支持旧压缩包时仅移除 `LCPZ` 分支，保留 `DVZ1` 和限制。 |
| 静态数据包装 | `LegacyProjectDataNormalizer.normalize` 将未包含 `value` 的 `staticData` 包装为 `{value: 原内容}`；已包含 `value` 的数据保留，不遍历用户静态值内部做同名字段转换。 | 停止支持这种旧项目数据后移除对应分支。 |
| 循环容器间距 | 同一转换器把 `LoopContainer.style.gap` 移到 `horizontalGap`、`verticalGap`；已有新值优先，旧字段移除。 | 停止支持旧间距配置后移除对应分支。 |
| 表格滚动选项 | 同一转换器把 `autoScroll` / `enableScroll` / `enableInfiniteScroll` / `infiniteScroll` 映射为 `enableCarousel`，`scrollSpeed` / `speed` 映射为 `carouselSpeed`，`scrollPauseSeconds` / `pauseSeconds` 映射为 `carouselPauseSeconds`；已有新值优先并移除旧字段。 | 停止支持这些旧表格字段后移除对应分支。 |
| 旧图表配置类型修复 | `repairLegacyChartConfigTypes` 仅在图层类型明确匹配时，将分组玫瑰图的 `AntdBaseRose` 改为 `AntdGroupRose`，将词云图的 `AntdBaseWordCloud` 改为 `AntdWordCloud`。 | 不再支持受影响旧项目时移除；保留其余图表与用户数据。 |
| 数据库名称别名 | `resolveImportedDatabaseType` 将 `PostgreSQL`、`MSSQL` 映射到 Web 枚举，并忽略受支持名称的大小写；这是 Desktop 包互导也可能需要的名称映射，未知类型报错。 | 确认不再需要相关 Desktop 包及别名后仅收紧别名分支，保留当前枚举类型。 |

## 旧自定义组件

用户决定：CLI 版本未知的旧组件按现有静态规则处理；可转换的继续转换，无法可靠转换的拒绝并提示。实际使用中遇到的问题记录在 [新版使用问题列表](./新版使用问题列表.md)，不以未经核对的版本号单独拒绝，也不据此宣称所有版本行为一致。

| 项目 | 实现与处理 | 移除或复核条件 |
| --- | --- | --- |
| 旧组件识别与转换 | `LegacyComponentImportGuard` 在无清单包和清单包的单文件、组件压缩包导入时检查；`legacy-component-converter.js` 静态识别已知入口、CLI 资源加载模板及 `LightChaserInterface`、`LightChaserUtil`、`LightChaserUI`、`LCPUI`、`LCPSDK`、`LCPTypes` 的允许成员，并转换为新版接口。未知成员、动态访问及无法确认的代码会拒绝整个项目包；接口向用户返回组件名称和具体原因，异常会触发事务回滚与已写入文件清理。 | 停止支持旧组件后移除守卫、调用和转换脚本；新组件的导入、解压与安全检查仍需保留。 |
| 旧组件 UI 样式 | `LegacyUiStyleConverter` 和 `legacy-ui-style-map.properties` 转换已识别的旧类名、选择器和 CSS 变量；组件转换脚本也处理可确定的 `className`。不能安全判断的样式会报错。 | 停止支持旧组件样式时移除相应转换、映射与调用；保留新组件样式。 |
| 旧 `ObjectUtil.merge` 行为 | `legacy-component-converter.js` 将已确认的旧 `ObjectUtil.merge` 调用替换为写入组件文件的局部实现。**该实现随转换后的组件在运行时执行**；不暴露旧全局接口。因此，它属于导入时生成、运行时保留旧行为的例外，不能描述为仅在导入时执行。 | 如严格要求运行时也不保留旧语义，需另行决定用新版行为替代还是拒绝含该调用的组件，并验证受影响项目；当前盘点未改变其行为。 |

## 新旧包共用的导入逻辑

这些逻辑可能处理旧来源，但不能当作纯旧兼容整体删除：

- `ImportedAssetContext.resolveImportedAssetUrl` 依据已登记映射处理本地相对路径、旧机器路径、`http://asset.localhost/` 和 `asset://localhost/` 等 Desktop 地址，并保留查询和片段；外部 URL 只在明确映射时改写，同名歧义报错。`rewriteImageAssetUrl`、`rewriteVideoAssetUrl`、`rewriteModelAssetUrl` 将引用写回项目；当前 Desktop 包也需要资源映射，缺失资源会提示。
- `rewriteCommonApiId`、`rewriteDatabaseTargetDb`、`rewriteScreenReferenceProjectId` 在新环境中重建数据源和页面引用；无法映射的数据源或单项目页面引用会清空并提示。多项目图引用按映射重写并校验。这是导入迁移，不是旧数据库或账号兼容。
- `registerImportedFont` 和 `ImportedFontFamilyRewriter` 处理字体同名及项目中字体名改写，新旧包均使用；不能因停止旧格式支持而整体移除。
- 加密、资源文件与清单检查、大小限制、事务回滚及当前 `DVZ1` 解码也服务新版包；不能与旧分支一起删除。
- `.lcp-agent-workspace` 检查用于阻止覆盖旧工作区数据，不读取或迁移旧数据，也不属于项目包导入兼容；保留独立的数据保护标记。

## 验证与限制

`ProjectArchiveComponentConversionTest` 覆盖合成旧包、两种旧压缩、旧字段、图表修复、资源映射、数据库别名及失败处理；`LegacyComponentImportGuardTest`、`LegacyUiStyleConverterTest` 覆盖组件和样式转换；`ImportedFontFamilyRewriterTest` 覆盖通用字体改写；`ProjectArchiveCompatHelperManifestSerializationTest` 覆盖清单模式；`ProjectArchiveTransactionTest` 覆盖事务边界。测试结果以本次实际运行报告为准。

无清单包和版本 1 清单仍缺真实样本；真实项目的组件、资源和完整浏览器交互，以及 Web / Desktop 真实包双向导入，仍按原待办继续验证。本清单不宣称支持所有旧版本，也不替代上述验收。
