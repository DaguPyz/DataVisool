# 主编辑器插件化迁移计划

本轮计划新增 **14 个内置插件**，包括 13 个主编辑器插件和 1 个供编辑、预览、发布共用的运行时插件。首批落地共享运行时和编辑器外壳。迁移以旧项目能按原有流程打开、编辑、保存、预览和发布为验收主线。

本轮覆盖 `/designer?id=…`、主编辑器内的全部功能入口，以及预览和发布对共享运行时的接入。`/preview?id=…` 和 `/release/:id` 沿用现有页面入口完成兼容验收，两页各自的插件化放到后续批次。 [现有路由](../datavisool-app/src/plugins/legacy-routes/legacyRoutes.tsx)

## 插件清单

| 序号 | 插件 | 职责 |
| --- | --- | --- |
| 1 | 共享运行时 | 按项目和运行模式加载与释放项目，管理项目数据、组件注册与渲染，承载远程组件、动态脚本、字体和蓝图执行。提供项目数据快照和必要的读写操作。 |
| 2 | 编辑器外壳 | 注册编辑器路由，处理页面挂载、加载失败和重试。提供画布、工具栏和面板的注册位置，负责布局、窄屏面板互斥、焦点恢复及入口的显示顺序。 |
| 3 | 画布 | 管理视口和选区，负责拖拽、缩放、标尺、吸附、排版和主画布的撤销重做。提供图层选择、插入和修改等编辑操作。 |
| 4 | 项目操作 | 管理手动保存、自动保存、本地快照恢复、画布修复、封面和导入导出。负责项目、画布、全局主题和全局滤镜设置入口，以及预览和发布配置入口。 |
| 5 | 属性配置 | 根据选区提供组件属性、样式、数据、状态、滤镜与主题配置，接入现有组件配置界面和底部的组件代码编辑入口。 |
| 6 | 快捷键 | 管理用户快捷键配置、帮助和键盘及剪贴板监听。将快捷键转为对画布、项目操作、蓝图和其他已注册功能的调用。 |
| 7 | 蓝图编辑 | 负责蓝图页面、节点、连线、编辑交互和蓝图撤销重做。通过运行时操作更新蓝图数据，由运行时负责预览和发布时的执行。 |
| 8 | 组件库 | 展示、搜索和分类浏览可用的内置组件与服务器组件，通过画布操作添加组件。 |
| 9 | 资源库 | 管理编辑器内图片、视频等资源的列表、筛选和相关操作，向画布插入资源。 |
| 10 | 图层 | 展示图层树，提供搜索、选择、显隐、锁定、排序和编组入口，通过画布操作更新图层。 |
| 11 | 模板库 | 查询、搜索、删除与插入模板，接管图层右键的保存为模板入口。 |
| 12 | 全局变量 | 提供全局变量及其数据源配置的界面，通过运行时读取和更新当前项目或场景的变量。 |
| 13 | 子项目 | 管理子项目列表、创建、重命名、删除和切换。切换时调用项目保存与加载操作。 |
| 14 | AI 驱动 | 管理对话、模型选择、运行设置、任务进度和停止操作，通过编辑操作读取及修改当前画布。 |

现有编辑器直接装配顶部、左右两侧和底部区域。迁移时由外壳负责摆放这些区域，插件把自己的入口和组件注册到相应位置。例如底部的缩放属于画布，快照恢复属于项目操作，快捷键帮助属于快捷键插件。 [现有页面装配](../datavisool-app/src/plugins/editor-shell/Designer.tsx#L158-L178) · [左侧面板与 AI 入口](../datavisool-app/src/plugins/editor-shell/dock/DesignerLeft.tsx) · [顶部工具栏](../datavisool-app/src/plugins/editor-shell/header/DesignerHeader.tsx) · [底部工具栏](../datavisool-app/src/plugins/editor-canvas/DesignerFooter.tsx)

## 状态归属与插件协作

编辑、预览、发布共用组件注册、渲染和资源释放流程。各入口传入模式，由运行时选择对应的加载器和事件规则。 [模式分发](../datavisool-app/src/plugins/designer-runtime/designerRuntimePlugin.ts#L7-L34) · [事件规则](../datavisool-app/src/plugins/designer-runtime/internal/designer/loader/DesignerLoader.ts#L398-L405)

| 场景 | 数据来源与访问方式 | 加载后的行为 |
| --- | --- | --- |
| 编辑 | 按项目 ID 通过登录态的项目接口读取已保存数据。 | 挂载编辑工具，修改可保存到项目。加载时跳过自动触发的组件加载完成事件、蓝图全局加载完成和定时事件。 |
| 预览 | 通过同一个项目接口读取已保存数据。编辑器里的预览按钮先保存再打开预览页。 | 展示画布，允许体验项目交互，并按运行规则触发加载完成和定时事件。 |
| 发布 | 按发布 ID 读取发布时生成的项目包及其中的资源。开启密码保护时，访客需要先通过密码校验。 | 展示发布画布，按运行规则触发加载完成和定时事件。公共 API 和数据库查询走发布专用接口。 |

- **项目数据由运行时管理。** 当前加载器负责读项目、注册组件并初始化运行环境，项目管理器汇集画布、图层、主题、滤镜、变量和蓝图数据。迁移时按一次项目打开到关闭的生命周期管理这些数据，项目操作插件使用运行时给出的快照执行保存和导出。编辑、预览与发布分别按自己的模式加载。 [项目加载器](../datavisool-app/src/plugins/designer-runtime/internal/designer/loader/DesignerLoader.ts#L374-L413) · [项目管理器](../datavisool-app/src/plugins/designer-runtime/internal/designer/manager/DesignerManager.ts#L30-L91)
- 保存和导出使用当前可独立保存项目的快照。在子项目发起发布时，发布仍使用主项目快照。导入在打开文件选择器前绑定目标项目。
- **选区和主画布编辑历史由画布插件管理。** 图层面板点选图层时调用画布的选择操作，属性面板订阅选区变化。属性修改、模板插入和 AI 修改走对应的编辑操作，沿用现有保存与撤销语义。
- **界面入口由功能插件登记。** 外壳提供面板、工具栏、弹窗和命令入口的注册能力。功能插件依赖外壳提供的注册能力，外壳按登记内容装配页面。这样新增面板只需登记入口。功能模块在进入编辑器或使用相应入口时按需加载。
- **跨插件协作用 SDK 契约。** 需要执行操作并取得结果时调用能力，例如保存或切换项目。已经发生的变化用事件通知，例如选区变化。依赖通过 `requires` 和 `provides` 声明，公共契约放在插件实现目录之外。现有组件全局接口由运行时提供兼容适配，新的插件通过 SDK 契约交换状态。 [插件改造大纲](./一切皆插件改造大纲.md#二插件的内容边界) · [现有组件运行时入口](../datavisool-app/src/plugins/designer-runtime/internal/legacy-global/ComponentRuntime.ts)
- **历史记录绑定创建它的编辑场景。** 每次打开或切换出的编辑场景都有独立的内存标记，修改入队和撤销重做同时核对该标记与版本，避免同版本号的旧记录混入新场景。该标记不写入项目文件。未能登记历史的修改必须恢复已改数据；这类失败回滚与用户主动撤销分开，退出准备期间仍能完成必要恢复。

## 执行批次

| 批次 | 交付 | 合入条件 |
| --- | --- | --- |
| 0. 建立迁移基线 | 记录当前提交，跑生产构建和现有回归用例，记录通过、失败和跳过。用同一份旧项目记录完整编辑链路，准备允许写入的隔离后端。 | 有可重复的测试命令、可复用的项目样本和已知问题记录，供后续比较。 |
| 1. 共享运行时与外壳 | 落地插件 1、2。通过现有加载器建立运行时能力，接通编辑、预览、发布三种模式。把编辑器路由注册从 `legacy-routes` 迁到外壳，并在同批撤下旧注册。现有功能经迁移期间的适配接入外壳。 | 通过控制台新建、项目列表打开、路由直达和刷新验证入口。覆盖加载失败重试、退出后重进、快速切换项目，以及预览、发布和远程组件渲染。 |
| 2. 画布与项目操作 | 落地插件 3、4。收拢选择、修改及历史操作，迁移保存、自动保存、恢复、导入导出和预览发布入口。 | 旧项目可编辑并保存后重开。覆盖撤销重做、手动与自动保存、失败重试、快照恢复及未保存退出。 |
| 3. 编辑面板 | 落地插件 5、8–13。逐个迁移右侧属性配置和六个左侧业务面板，逐项移除对应的旧入口。 | 核对面板顺序、中英文、窄屏互斥和键盘焦点。验证图层与选区联动、资源与模板插入、变量更新以及主子项目分别保存。 |
| 4. 快捷键、蓝图与 AI | 落地插件 6、7、14，撤掉已迁功能的旧接线。 | 同一快捷键只触发一次，复制粘贴和输入框行为符合基线。覆盖蓝图编辑与执行、AI 修改后的保存与撤销、任务停止和跨项目状态清理。 |
| 5. 整体验收 | 检查全部 14 个插件的依赖声明、公共契约和生产装配，清理失去调用方的迁移适配，重跑完整回归和生产构建。 | 使用基线旧项目走通打开、编辑、保存、关闭后重开、预览、发布及访问发布页。隔离后端的必测流程有实测结果。 |

## 生命周期与回退

1. **打开和切换项目。** 取消前一次加载及所属的只读请求。请求返回时确认它仍属于当前这次加载，再更新画布和面板。同一项目重试也要作此检查。进入子项目时按既有流程处理当前项目的未保存修改。
2. **退出编辑和停用插件。** 保存按现有流程处理。用户取消退出或保存失败时保留编辑现场。确认退出后撤销界面入口和订阅，释放监听、定时器、在途读取和渲染实例。资源按登记它的所有者撤回，旧加载器的清理不得删除新加载器仍在使用的资源映射；某项清理失败时继续处理其余资源，最后汇总错误。编辑器路由按现有路由插件的生命周期随应用卸载。 [现有页面清理](../datavisool-app/src/plugins/editor-shell/Designer.tsx#L99-L139) · [路由注册的停用条件](../datavisool-app/src/plugins/router/routerPlugin.tsx#L60-L78)
3. **按批回退。** 每批把新注册、旧入口撤销和对应适配放在同一组提交中。回退时成组恢复，确保每个路由和功能入口只有一处注册。沿用当前项目数据格式、已有 API 和组件兼容接口，验证迁移后保存的数据能被回退版本读回。

## 实施结果

14 个插件的创建入口、生产装配、能力声明与私有源码归属已落地，静态边界检查通过。以下归属已经完成：

- 运行时持有加载器、管理器、渲染器、组件目录、变量和蓝图执行，以及 Group、LoopContainer、ScreenReference 内置组件；编辑、预览、发布继续保留各自的取数和自动事件规则。
- 画布持有交互、选择、视口、右键菜单、历史和场景状态；外壳持有布局、dock 和入口贡献；快捷键持有按键监听及配置。画布入口登记轻量能力，进入编辑场景时才加载实际运行时。
- 属性插件持有配置界面与状态；蓝图插件持有节点配置、绘制、连线、拖拽、视口及编辑历史。两者通过公开场景能力修改项目，不直接读取运行时管理器。
- 项目操作、组件库、资源库、图层、模板、变量、子项目和 AI 各自持有专用界面、状态、资源和退出清理；通过声明的能力与内核事件协作。
- 公共快照与历史同时校验场景身份和版本；失败回滚可在暂停时完成。历史按图层实体整体处理新增、删除及挂载后生成的配置，已有实体的字段修改仍执行差量冲突校验。合法编组导致的视图重挂及历史删除恢复使用运行时私有实体身份保持旧历史连续，新的视图仍创建新实例；未登记的控制器替换和同 ID 的无关重建仍拒绝。循环容器导航期间保留内部画布所有者，返回时先保存修改再释放旧实例。

本轮 14 个目标插件已完成拆分及验收。旧 V1 保存重开、预览与发布页蓝图、子项目发起主项目发布、密码访问、迟到 AI 作用域隔离及编辑／预览／发布三种模式的行为差异均已验证。

- 完整组件 207 个文件、886 项通过，无失败、无跳过。
- 隔离浏览器整轮 26 个文件、294 项通过；最后实体历史补充修复后，19 项受影响浏览器再次通过。
- 正式 Web 默认回归 113 项通过、588 项因环境配置跳过；Web／Desktop 生产构建通过，Desktop 15 项检查通过，三个共享包产物均为 0 差异。
- 最终 Web 生产入口静态依赖不包含画布运行时，画布实现仅经动态导入可达；插件／包边界、类型和打包公共 API 检查通过。
- 隔离测试后端、数据库与测试凭据已清理。完整结果见 [主编辑器插件化迁移测试报告](../测试报告/主编辑器插件化迁移/主编辑器插件化迁移测试报告.md)。

预览页和发布页各自的入口插件化仍按本计划范围留给后续批次；本轮已完成它们对共享运行时的接入和兼容验收。
